# External skill review

Selection criteria: a recurring task, a distinct result, evidence for checking that result, and a useful path without installing another platform. The review screened repository trees and catalog descriptions, then examined representative instructions for the shortlisted workflows. Large catalogs include translations, duplicate packages and vendor-specific actions. This was a portfolio screen, not a behavioral audit of every listed third-party skill.

All four new workflow texts and the scorer were written for this collection. No source installer, hook, dataset, prompt file or service connector was bundled.
