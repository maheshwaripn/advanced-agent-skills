# Trace Architecture

Trace one behavior across a codebase with revision-specific evidence and an explicit map of unknowns.

Invoke `/trace-architecture` when you need this outcome.

## Worked scenario

A handler and producer share a payload type, but the subscription is configured elsewhere. Show the observed components and flag the missing subscription. Do not draw a confirmed delivery edge.
