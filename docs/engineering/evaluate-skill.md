# Evaluate Skill

Compare two skill or prompt revisions on paired cases and report regressions, reliability and cost.

Invoke `/evaluate-skill` when you need this outcome.

## Worked scenario

The candidate wins two routine tasks but leaks expected answers on a held-out case. Reject that comparison, repair isolation and rerun both arms.
