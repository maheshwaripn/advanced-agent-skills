# Review UI Journey

Evaluate a real user journey across interface states, keyboard navigation and responsive layouts.

Invoke `/review-ui-journey` when you need this outcome.

## Worked scenario

A form works on desktop but a sticky footer covers Retry on mobile. Record viewport, failed state and keyboard reachability. Verify successful recovery with the original field values after the fix.
