# Draft Release Notes

Write audience-facing release notes from a verified comparison between two revisions.

Invoke `/draft-release-notes` when you need this outcome.

## Worked scenario

A comparison adds CSV export and reverts it before the candidate, renames a CLI flag, and changes a private helper. Cover the flag with a verified replacement invocation. Omit CSV export and the private refactor.
