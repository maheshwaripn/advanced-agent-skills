# Keyboard Shortcuts

Identify host version and active context. Read its documented binding syntax, inspect conflicts, then apply one binding at the requested scope. Verify the action and retain the previous assignment for recovery.

## Illustrative request

An editor shortcut shadows a terminal action.

## Expected result

Show the conflict and confirm both actions in their intended contexts.
