# Spreadsheet Workbook

Identify grain, input fields, formulas, units and output tables. Keep assumptions editable. Recalculate, check totals and error cells, then inspect the workbook after reopening. Preserve existing sheets unless edits require changes.

## Illustrative request

Build a sample monthly utilization workbook.

## Expected result

Changing an input updates totals and missing capacity never produces a misleading percentage.
