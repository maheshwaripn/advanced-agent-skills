# Document Drafting

Identify the reader, decision and source facts. Build a short outline, draft with explicit evidence and review terminology, claims and requested format. The VPS docs skill concerns editable shared documents. For a shared-document request, verify the document identity and edit permissions, preserve existing sections, and confirm the resulting change. Word-file delivery belongs to the word-document workflow.

## Illustrative request

Draft a one-page project decision brief.

## Expected result

Include options, decision owner, rationale and unresolved evidence.
