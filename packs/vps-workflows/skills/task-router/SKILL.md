# Task Router

Assess ambiguity, dependencies, verification cost and reversibility. Keep small deterministic work local. Split only independent tasks with clear evidence contracts. Map roles to available capabilities; verify worker claims through a source or executable check. Record any fallback to sequential work.

## Illustrative request

Two read-only workers can inspect docs but cannot run tests.

## Expected result

Assign independent document checks, then give the parent the test and final decision.
