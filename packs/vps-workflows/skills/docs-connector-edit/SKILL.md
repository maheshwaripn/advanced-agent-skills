# Docs Connector Edit

Resolve document identity and target text. Read the relevant section and revision. Apply the smallest supported update and confirm nearby text, formatting and revision. Distinguish native Docs from uploaded documents.

## Illustrative request

Update one heading that appears twice in a sample document.

## Expected result

The intended section changes while the other occurrence is preserved.
