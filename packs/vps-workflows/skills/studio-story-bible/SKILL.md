# Studio Story Bible

Extract immutable character traits, setting, timeline and visual rules from the approved premise. Separate creative choices from open questions. Give each recurring character and prop a stable ID and keep revision notes.

## Illustrative request

A child repairs a blue radio across three scenes.

## Expected result

Create a character and prop sheet that fixes the radio color and marks its repair state per scene.
