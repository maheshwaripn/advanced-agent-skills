# Plugin Authoring

Confirm supported manifest schema and install path for the chosen host. Define identity, list actual skill directories, document permissions and use a clean fixture install. Check discovery, duplicate names and uninstall behavior.

## Illustrative request

Package two sample skills where one manifest path is stale.

## Expected result

Validation identifies the path and a corrected install discovers both commands.
