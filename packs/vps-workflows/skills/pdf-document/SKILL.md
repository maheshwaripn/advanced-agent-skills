# Pdf Document

Inspect page count, dimensions, text extraction and intended output. Check font rendering, clipping, images and links on representative pages. If only structural inspection is possible identify the missing visual checks.

## Illustrative request

Check a report whose wide table approaches the page edge.

## Expected result

Report the affected page and distinguish clipping observed in rendering from a suspected issue.
