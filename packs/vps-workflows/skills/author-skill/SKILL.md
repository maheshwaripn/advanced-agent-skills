# Author Skill

Pick one distinct outcome, invocation boundary and prerequisites. Write the steps and failure path, include a synthetic input and expected result, validate packaging and test against a near-miss case.

## Illustrative request

Create a skill for reconciling report totals.

## Expected result

A mismatch is reported and a file with no comparable totals yields insufficient evidence.
