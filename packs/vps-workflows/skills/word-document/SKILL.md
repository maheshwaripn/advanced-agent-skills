# Word Document

Inspect an existing template or establish page and style requirements. Preserve fields, headings and tables. Save a separate revision when appropriate. Render and inspect page breaks if supported, and disclose any unverified layout.

## Illustrative request

Create a two-page SOP with a revision table.

## Expected result

The DOCX reopens, headings are structured and the table fits the page.
